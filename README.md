# hy263.github.io

Personal academic website of Hyunjoo Yang, built with GitHub Pages (Jekyll, no theme).

## How to update
- Papers and data sets: edit `_data/papers.yml` (copy an existing entry). The site rebuilds on push.
- Name, bio, links, education: edit `_data/profile.yml`.
- Layout: `_layouts/default.html`, `_includes/paper.html`, `assets/style.css`.
